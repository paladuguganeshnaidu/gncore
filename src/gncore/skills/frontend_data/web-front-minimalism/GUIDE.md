# GNCore Minimalism

Reduce competing emphasis rather than hiding necessary actions. Use a compact type scale, a neutral surface system, and one purposeful accent. Align content to a consistent grid; give primary and secondary actions distinct weight. Preserve explicit loading, empty, error, and success states. Check long labels, zoom, keyboard focus, and narrow screens.

## Working agreement

Implement the user's requested artifact in the existing stack and design system. For a style request, apply this direction without combining every installed style. Check narrow and wide layouts, keyboard interaction, content overflow, and relevant loading or error states. Use reduced-motion alternatives for motion. Report actual checks and unresolved limitations.
