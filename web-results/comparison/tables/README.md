The final three-entrypoint adaptive follow-ups are separate; the executive footer records their allocation checks without replacing earlier results. Original means frozen GNCore at cd77d82. Reference means one task-matched guide per category from 14 pinned source repositories, not a company-wide score. VS Code/Copilot is a host and is not evidence for standalone Codex skills.

All 29 non-UI holdout categories are fully reviewed, with 173 applicable criteria per arm. Web-frontend remains incomplete and displays Not measured in the category table. Static inspection is not substituted for rendering. Security recall, proposed repair review, false-positive rate and actual code execution remain separate metrics.

Plotly-related skills were not specified or tested in this pilot. No standalone Codex skill collection was run as a controlled comparison. Both remain explicitly unmeasured. Feature cards describe verified GNCore behavior; competitor feature absence was not audited.

These are single unblinded pilot results, with uncontrolled host/model/context effects and no repeated-trial or no-added-skill estimate. Percentages are task-check pass fractions, not universal efficiency, broad security assurance, visual quality or statistical superiority.
