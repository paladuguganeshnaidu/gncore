# GNCore public benchmark figures

Regenerate with `python scripts/build_public_benchmarks.py`. Charts use original measurements, the GNCore palette, denominators and explicit scope. Data sources and SHA-256 digests are in benchmark-data.json.

The IDE results are the historical 29 October pilot, not a fresh evaluation of 7.0.0. Withdrawn development quality scores and adaptive follow-ups are not mixed into that comparison. The public charts do not establish causal gains, universal security or a ranking of AI vendors. Source-specific attribution remains in the linked snapshots.
