GNCore 7.0.0 developer command reference

Install a source checkout with:
python -m pip install .

For the verified PyPI release:
python -m pip install gncore==7.0.0

Discover and inspect:
gncore list skills
gncore list domains
gncore list workflows
gncore search "neural network"
gncore route "Check neural network gradients"
gncore show neural-networks

Export and verify:
gncore export --specific neural-networks
gncore export --skills web-frontend web-backend
gncore export --all --prune-retired --dry-run
gncore export --all --prune-retired
gncore verify
gncore audit
gncore evaluate --validate
gncore export --all --output gncore-developer-skills.zip

Default project location: .agents/skills/<category>/SKILL.md
Compatible host agents discover and load these skills according to their settings.
